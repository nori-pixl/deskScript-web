.ds file / desk & drawer 比喩言語

引き出しを
開けたら、処理が
出てくる。

deskScriptは、オフィスの「デスク」と「引き出し」の比喩でプログラムの流れを表す、実験的な自作スクリプト言語です。 承認印を押すように分岐し、鍵付き引き出しのように排他ロックをかけ、共有キャビネットのようにデータを持ち回ります。

deskScript v1
SAMPLE — greetDesk.ds 
desk:greetDesk(string name){
   drawer:greetDrawer(action01){
      host.var.string:userName(id, name)
      inreturn:greetReturn{
         "こんにちは、", userName, "さん！\n"
      }
   }
   outreturn{ greetReturn }
}
01 — Overview

deskScriptとは

処理のまとまりを desk（デスク）、その中の実処理を drawer（引き出し）として書きます。デスクに引数を渡して呼び出すと、対応するdrawerの inreturn ブロックが評価され、outreturn で指定した結果が文字列として返ります。

グローバル変数

set:var

set:var(型, global/スコープ/変数名) = 値 でプロセス内グローバル変数を定義します。

関数

function:

function:名前(引数){...} で再利用可能な処理を定義できます。

イベントフック

timing:

timing:キー{...} でデスク開始/終了、ロック/アンロック、変数変更/削除、for・foreverの開始/終了などにフックできます。

ブラウザのDOM操作

HTML.document

import.ds.txt に HTML と書くだけで、HTML.document.getElementById(...) のように本物のDOM操作がそのまま呼べます（wnode.js経由でブラウザ実行時）。

02 — First Sheet

最初の一枚

デスクを1つ書いて、引き出しの中の処理を実行してみます。

desk:approveRequest(string reviewResult){
   drawer:mainDrawer(action01){
      host.var.string:result(id, reviewResult)
      inreturn:decision{
         stamp(result):approved{
            "決裁印が押されたので次工程へ。\n"
         }
         :rejected{
            "差し戻しです。\n"
         }
      }
   }
   outreturn{ decision }
}
03 — Reference

制御構文

ネストする構文（ifの中にforがあるなど）は、テキスト上で一番外側にあるものから正しい順で処理される統一ディスパッチャで動いています。

if / elif / else

分岐

if(条件):true{...} elif(条件):true{...} else{...}

switch / case

分岐

switch(対象):case("値"){...} default{...}

while

ループ

while(条件):true{...}。安全上限あり（既定1000回）。@setinで名前を付けて明示的に止めることもできる。

for

ループ

for(dis.var:名前 in ++1):N{...} end{...}

forever

ループ

forever{...}（引数なし）。同期実行のため安全上限つき。@setin制御と組み合わせて使う想定。

try / catch

例外

try{...} catch(dis.var:変数){...} end{...}

04 — Reference

クラス

その場でインスタンスを作って使い切る、簡易なフィールド＋コンストラクタです。

set:class(Worker, string:name, int:age)
class:Worker(self, self.string:name, self.int:age), init(self.string:name, self.int:age | "no-name", 0){
   "Worker初期化: ", self.name, " (", self.age, ")\n"
}

// 使う側
new:Worker("Alice", 30)
05 — Reference

オブジェクト（object:）

クラスとは別物。複数のdrawer間で値を持ち回るための、共有／専用／使い捨てのレコードです。deskの外側でスキーマを宣言します。

object:UserProfile(type=global){
   userName:string:notnull
   age:int
   code:string:len[4]
   mail:string:re[^[a-z]+@[a-z]+$]
}

desk:saveProfile(string name){
   @object(name=UserProfile)
   drawer:d(action01){
      host.var.string:name(id, name)
      inreturn:r{
         object:UserProfile.new(userName:string=name, age:int=20, code:string=AB12, mail:string=abc@xyz),
         "登録名: ", UserProfile.userName, "\n"
      }
   }
   outreturn{ r }
}

type=global

共有

同じ @object(name=名前) タグを付けた複数のdrawerで共有される共有メモリ。

type=host

専用

@object(name=名前) を付けた1つのdrawer専用の領域。他のdrawerからは見えない。

type=null

使い捨て

スコープ指定なし。そのdesk呼び出し1回の中だけ有効なローカル値。

フィールド制約

検証

notnull（必須）／len[N]（最大文字数）／re[正規表現]（パターン一致）が使える。

06 — Reference

@setin による名前付き制御

while・foreverの直前に @setin(name=名前, type=ctrl) を置くと、外部から止めたり再開したりできる名前付きハンドルになります。

desk:watchdogDemo(string dummy){
   drawer:d(action01){
      host.var.string:dummy(id, dummy)
      inreturn:r{
         @setin(name=watchdog, type=ctrl)
         forever{
            "ここは危険地帯。stopが効いていれば実行されない\n"
         }
      }
   }
   outreturn{ r }
}

timing:forever.start{
   setin:watchdog.stop()
}

停止

stop

setin:名前.stop() — 次回以降のループ実行を止める。

再開

start

setin:名前.start() / setin:名前.start(引数) — 停止状態を解除する。

削除

delete

setin:名前.delete(type=comp) は完全削除（復元不可）。type=leav は一時削除。

復元

add

setin:名前.add() — type=leavで削除された名前を復元する。

07 — Reference

ロック

引き出しやデスク単位で、鍵付き引き出しのような排他ロックがかけられます。

lock:drawer(sharedResource) {
   "同時に複数の処理がこの引き出しを開けられないようにします。\n"
}
unlock:drawer(sharedResource)

// timing指定つきのロック/アンロック
sharedDesk.lock(type=desk, timing=desk:targetDesk.start)
sharedDesk.unlock(type=desk, timing=desk:targetDesk.end)
08 — Reference

その他の構文

変数の即時破棄

shred / delete

shred:var(名前) / var:名前.delete() で変数を即座に破棄。

デスクの並列合流

meeting:join

meeting:join(deskA("arg"), deskB("arg2")) で複数デスクの結果を1つに合流。

デスク間メッセージ

outbox / inbox

outbox:send(key, value) / inbox:receive(key)。

audit:trail

audit:trail(変数名) で変数の変更履歴を記録。

09 — Convention

@タグと操作構文のペアリング規則

一部の構文は、desk/drawerの直前に付けるアノテーション（@タグ(...)）と、対応する操作構文（タグ:名前.method()）がセットになっています。今後この形式の構文が増える場合も、このペアリングに揃えます。

アノテーション対応する操作構文用途
@object(name=名前) object:名前.new(...)
名前.フィールド名		 オブジェクトスキーマのレコード作成・参照
@setin(name=名前, type=ctrl) setin:名前.stop() / .start() / .delete(type=comp|leav) / .add() while / foreverの名前付き外部制御

※ set: は set:var / set:class / set:desk と衝突するため、@set ではなく @setin / setin: にしています。

応用法

01

CLIツールとして

Node.jsから index.js を直接実行し、承認ゲート・監査ログ・排他ロック・共有オブジェクトを使った業務フローを、比喩ベースの自動化スクリプトとして走らせる。

02

ブラウザの動的HTML操作

wnode.js をHTMLに埋め込み、main.dsをブラウザ上で実行。HTML.document.〜経由でDOMを書き換えたり、イベントを後付けしたりできる。

03

学習・実験用の自作言語として

構文追加は src/blocks/ に1機能1ファイルで追加し、ネストする構文ならNestableDispatcher.tsに登録するだけ。独自構文の試作台として扱いやすい。

12 — Reading Room

使うときの注意点

eval相当の仕組みで動いている

式の評価は内部的に new Function(...) を使っています。process / require / Function / eval / constructor / __proto__ などを含む式は拒否しますが、これは簡易的なブロックリストで完全なサンドボックスではありません。信頼できない第三者が書いた.dsを実行するのには向いていません。

カンマの扱い

出力の組み立ては「トップレベルのカンマ」で区切る方式です。文字列内・括弧内のカンマは区切りとして扱わないよう修正済みですが、複雑な式では括弧の対応やクォートの閉じ忘れに注意してください。

構文エラーは出力に混ざる

失敗を黙って握りつぶさない設計のため、式を間違えると [Eval Warning] がそのまま出力文字列に出てきます。デバッグの目印として使えます。

while / foreverには安全上限がある

無限ループでハングしないよう、既定で最大1000回まで実行すると強制的に打ち切られます。それより前に確実に止めたい場合は @setin(name=名前, type=ctrl) を付けて setin:名前.stop() を呼んでください。

状態がプロセス内に残り続ける

ロック状態・監査ログ・クラスのインスタンス・objectの共有レコード・@setinの制御ハンドルは、明示的にクリアする手段がありません（objectのtype=nullのみdesk呼び出しごとにリセット）。1回のスクリプト実行で完結させる用途を想定しています。

生成メッセージに実行可能な構文パターンを書かない

内部の確認メッセージに 名前.add() のような実行可能構文をそのまま含めると、次のスキャンで本物の呼び出しとして誤爆することがあります（実際に踏んだバグです）。独自構文を追加する際も注意してください。

正規表現ベースの簡易パーサーである

文字列の中に { や } を書くと、波括弧カウントを誤爆させることがあります。厳密なAST/トークナイザではないため、複雑な入れ子構造は小さく試してから組み込むのがおすすめです。

@タグは直後の構文にしか紐付かない

@object(name=X) はその直後のdrawer:に、@setin(name=X, type=ctrl) はその直後のwhile/foreverに、空白・改行を挟んで直接続けて書いてください。間に他の文が挟まると紐付きません。
